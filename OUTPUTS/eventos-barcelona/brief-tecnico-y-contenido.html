Infraestructura y performance

Live

Cloudflare Free por delante de CDmon

Instalado el 3 sep 2026 con la cuenta dev@eventosbarcelona.com. Zone activa, SSL Full (no strict, CDmon origin cert), Page Rules, DNS auditado. Cambio de nameservers desde CDmon a Cloudflare completado por Xavi. TTFB pasó de 3.470 ms a 30 ms. Purga automatizada tras cada publicación desde script Node vía API v4.

Live

Transform Rule para Cache-Control

CDmon envía max-age=172800 (2 días) para HTML desde origin. Regla de transformación en Cloudflare que reescribe la cabecera para que las novedades lleguen al front al momento sin depender de un cambio en el origen que requiere FTP.

Live

Elementor cache purge estandarizado

Al editar _elementor_data vía REST, el frontend seguía mostrando HTML viejo. Fix: DELETE /wp-json/elementor/v1/cache incorporado a cada script de publicación + reset de _elementor_css para regenerar el CSS por página.

Escritura y publicación autónoma en WordPress

Live

mu-plugin eb-mcp-write (v1.18)

10 abilities MCP de escritura sobre WordPress: eb/create-draft, eb/set-elementor, eb/set-seo, eb/set-language, eb/move-post-type, eb/register-media, eb/clone-case, eb/render-elementor, eb/get-post-meta, eb/set-featured-image. Fuente en repo data/wp-mu-plugin/. Deploy inicial por FTP.

Live

REST directo para páginas publicadas

eb/set-elementor solo actúa sobre drafts. Para páginas ya publicadas, escritura directa vía POST /wp/v2/pages/{id} con meta._elementor_data. Round-trip byte a byte idéntico, sin corrupción de escapes. Sin necesidad de FTP.

Live

Gotcha del post_content divergente

Detectado el 14 sep: para algunas páginas legacy (ej. hub 4167 /produccion-tecnica-para-eventos/) el post_content tiene un HTML pre-generado por Elementor que diverge del _elementor_data. Escritura a meta persiste pero no cambia el render. Fix aplicado: snippet PHP output-buffer con str_replace.

Snippets PHP activos en Code Snippets

Live · ID 14

EB-AUDIT-100-V2-LINK-WEBMCP

Link headers (llms.txt, agent-card, mcp-card, agent-skills) + WebMCP navigator.modelContext loader + web-bot-auth (ed25519). Bypass de LLMagnet Pro toggles. Fallback canonical + meta description via output buffer si Yoast omite.

Live · ID 70

EB-CACHE-CONTROL

Headers Cache-Control para navegador. Estáticos: 1 año inmutable. HTML dinámico: public, max-age=300, s-maxage=1800, stale-while-revalidate=86400. Strict-Transport-Security con preload.

Live · ID 106

EB-FAQ-SCHEMA · auto-inject FAQPage JSON-LD

En single posts, parsea H2 "Preguntas frecuentes / FAQ" + pares H3+P y emite el schema FAQPage en wp_head. Aplica automáticamente a los 5 posts blog publicados esta sesión sin tocar el content del post (evita el bug de WP despojando <script> tags). Reutilizable para todos los futuros posts.

Live · ID 107

EB-I18N-TEMPLATE-SINGLE-BLOG

El template Single Blog (post 4176) trae strings hardcoded en inglés. En posts ES según WPML, output-buffer con preg_replace tolerante a whitespace traduce: "Corporate Event Success Studies" → "Casos de éxito en eventos corporativos", "See How we Have Delivered..." → "Descubre cómo hemos producido...". Extensible con más patterns.

Live · ID 108

EB-PRODUCCION-TECNICA-INTRO

Fix del post_content divergente del hub 4167. En template_redirect para page 4167, reemplaza el bloque INTRO viejo por content optimizado con 12 internal links a spokes técnicos y a las 4 landings MICE nuevas.

Sistema editorial · skill de copywriting

Live

Skill copywriting con 8 reglas duras

Codificadas para que ningún artículo o landing se dé por lista sin verificarlas:

  • Posicionamiento boutique premium · no directorio (anti unaplauso)
  • Prohibido em dash · reformular con comas/paréntesis
  • Bilingüe ES + EN obligatorio
  • Formato cards permanente en widgets de contenido
  • Verificación 4 vistas (ES/EN × desktop/mobile) antes de "listo"
  • Margen y ancho patrón /casos-exito/: boxed_width 1200 base + boxed_width_widescreen 1500
  • Featured image JPG landscape ≥1500px coincidente con el tema del artículo
  • Verificación WPML de internal links EN antes de publish (HEAD check batch)

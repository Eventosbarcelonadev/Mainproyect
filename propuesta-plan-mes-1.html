Plan del Mes 1 · Setup técnico + validación · Eventos Barcelona

Mes 1: dejar todo configurado y midiendo.

Las primeras 4 semanas no son para mover posiciones — son para dejar listo el motor: web cargada de "señales" para Google y para la IA, panel en vivo de métricas, todas las herramientas conectadas y midiendo. Cuando termine el mes, tenemos baseline real contra el que comparar cada cambio del mes 2 en adelante.

Duración
4 semanas
Esfuerzo total
~75-90 h
Foco
Setup + Baseline
Entregable principal
Dashboard live + KPIs medidos
Por qué este mes es invisible (pero crítico)

Setup que no se ve, pero condiciona todos los meses siguientes.

El mes 1 no genera leads nuevos. Lo que hace es poner el suelo en regla: instalar plugins profesionales, configurar señales técnicas para Google e IA, levantar el panel de medición, y resolver deuda técnica heredada (backlinks tóxicos de la agencia anterior, schemas incompletos, llms.txt inexistente). Sin este mes, cualquier acción del mes 2 corre sobre arena.

Semana 1

Días 1-7Auditoría técnica + instalación de stack profesional

22hEsfuerzo
◐
Auditoría SEO completa (9 categorías técnicas + 7 fases SXO + arquitectura + E-E-A-T) Crawl del sitemap (296 URLs en 7 sub-sitemaps detectados), análisis de schemas presentes, headers de seguridad, mobile, CTR vs benchmark del sector. Output: reporte con score técnico y quick wins priorizados.
8h
◐
Diagnóstico GEO/AEO (Generative Engine Optimization para IA) Evaluar visibilidad actual en ChatGPT, Claude, Perplexity, Google AI Overviews. Identificar gaps: /llms.txt sirviendo HTML genérico (no real), schemas faltantes (FAQ, LocalBusiness, Service), robots.txt sin referencia a llms.txt.
4h
◐
Instalación + configuración LLMagnet AI SEO Optimizer (v3.4.1) Plugin profesional para generación automática de llms.txt, tracking de bots IA (GPTBot, ClaudeBot, PerplexityBot, etc.), scoring de visibilidad y recomendaciones. Onboarding wizard, configuración de business profile, post types a incluir.
3h
◐
Instalación + configuración AEO God Mode (v1.6.15) Plugin complementario para Schema Engine, AI Crawler Log, Content Gap Scanner. Setup wizard, configuración de business type a "EventManagementCompany", social profiles (LinkedIn + Instagram), activación de 9 módulos (ai_crawlers, schema, local_business, robots, crawler_log, content_gaps, validator, GSC, aeo), conflict detector vs Yoast.
4h
◐
Verificación de plugins existentes (Yoast Premium 24.2, WPML 4.8.2, Elementor Pro 3.32, ACF 6.5) Inventario completo del stack ya pagado. Confirmar que la propuesta de SEO/GEO/AEO no requiere instalar nada más. Documentar uso del AI Generator de Yoast (premium feature ya pagada que da sugerencias automáticas de title/meta/keyphrase).
3h
Semana 2

Días 8-14Inyección de señales técnicas + endpoints para IA

24hEsfuerzo
◐
Headers HTTP de seguridad (HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy) Implementados sin necesidad de FTP/SSH (CDmon plan Junior no lo permite) usando el plugin Code Snippets para inyección PHP segura. Testing previo con CSP en modo Report-Only para no romper Elementor.
3h
◐
JSON-LD LocalBusiness en home (datos completos) Schema con address (Ronda General Mitre 126), phone (+34 653 979 329), email, openingHours (Mo-Fr 09:00-18:00), priceRange (€€-€€€), social profiles (LinkedIn + Instagram), areaServed (Barcelona + Spain). Validación con Google Rich Results Test.
3h
◐
Generación de /llms.txt y /llms-full.txt (estándar emergente para LLMs) Antes: la URL devolvía HTML genérico (404 efectivo). Ahora: 22.752 bytes con descripción real del negocio, 44 docs indexados, 24 posts en scope, links a categorías principales. Regeneración automática cada vez que se publica contenido nuevo.
2h
◐
Fix de robots.txt para que referencie /llms.txt y autorice AI crawlers explícitamente 15 AI crawlers verificados (GPTBot, ChatGPT-User, OAI-SearchBot, ClaudeBot, Claude-Web, anthropic-ai, PerplexityBot, Perplexity-User, Google-Extended, CCBot, Bytespider, meta-externalagent, Applebot-Extended, Amazonbot, cohere-ai). Endpoint llms.txt explícito en robots.
2h
◐
AI Agent Discovery: /.well-known/ai-agent.json, Link headers rel="mcp-server" y rel="ai-agent-card", alternate markdown per page Manifest con skills (list-services, search-content, get-content-markdown, get-pyramid-coverage), endpoints (llms.txt, sitemap, MCP server, REST API), license (crawl allowed, cite free with attribution). Link headers HTTP para discovery automática por agents.
5h
◐
17 abilities/tools del MCP server expuestas para consulta programática Visibility-score, bot-traffic, top-pages, recommendations, schema-status, page-visibility, attribution-stats, robots-txt-status, content-markdown, search-content, ai-visit-trends, regenerate-llms-txt, recalculate-visibility-score, send-report-email, bot-stats-table. Accesibles desde dashboard live y reportes mensuales.
4h
◐
Schema Scan completo (116 páginas indexables) Auditoría de structured data en cada URL del sitemap. Detección de schemas presentes (Article, Organization, BreadcrumbList, WebPage, ImageObject, WebSite, FAQPage en algunas), gaps de FAQ/Service/Event/Review.
3h
○
Resolución de conflictos schema Yoast vs AEO God Mode Decisión documentada: Yoast queda responsable de Article + Organization + WebPage (lo hace bien). AEO se encarga de FAQ + HowTo + custom schemas. Conflict detector activo monitoreando duplicados.
2h
Semana 3

Días 15-21Pirámide de keywords + auditoría URL por URL

20hEsfuerzo
◐
Pirámide SEO canónica formalizada (46 keywords en 3 niveles) Nivel 1 (marca · 14 KW): agencia de eventos Barcelona, MICE, DMC Barcelona, etc. Nivel 2 (categorías · 17 KW): grupos de música, alquiler iluminación, team building, etc. Nivel 3 (long-tail · 15 KW): contratar grupo de jazz, saxofonista para cóctel, mago corporativo, etc. Documento canónico marcado como "fuente de verdad" para futuras decisiones de contenido.
4h
◐
Mapping URL ↔ keyword (cobertura actual y gaps) Cruce de las 46 keywords contra las 296 URLs del sitemap. Resultado: 64% cobertura directa, 22% parcial, 14% gap. 12 páginas críticas identificadas a crear: 3 P1 (DMC Barcelona, team building, entretenimiento empresarial), 4 P2, 5 P3. Cada gap con URL propuesta + nivel piramidal + volumen estimado.
6h
○
Regla maestra bilingüe ES + EN documentada Toda página y artículo de EB tiene que existir en ambos idiomas, sin excepciones. WPML translation flow ya está activo. El sitemap respeta el patrón en /musica/ ↔ /en/music/, /danza/ ↔ /en/dance/, /artistas/ ↔ /en/artists/, /casos-de-exito/ ↔ /en/success-stories/. Las páginas nuevas tienen que mantener la simetría.
2h
○
Análisis de las 10 páginas top en GSC (CTR & posición) Identificación de páginas con muchas impresiones pero CTR muy debajo del benchmark de su posición. Resultado: 8 quick wins de titles/metas. Ej: /alquiler-iluminacion/ con 15.601 impr/90d pero CTR 0,15%. Reescritura propuesta lista para AI Generator de Yoast.
4h
○
Análisis de backlinks heredados (Rodanet, agencia anterior) Lista de backlinks tóxicos a investigar (kimonos, sitios irrelevantes). Preparación del disavow file para enviar a Google Search Console al final del mes.
4h
Semana 4

Días 22-30Panel de evolución + baseline + handoff

19hEsfuerzo
○
Dashboard en vivo de métricas SEO/GEO/AEO conectado vía REST + MCP Panel propio (propuestas.eventosbarcelona.com/dashboard.html) consumiendo en vivo los 17 endpoints LLMagnet + GSC + GA4. Visibility score, bot traffic, schema status, top pages, posiciones por keyword. Refresco automático cada 24h.
6h
○
Baseline congelado: foto exacta de hoy Snapshot de visibility score, agent readiness, CTR, posición media, impresiones, schemas presentes, bots IA detectados, conversiones. Versionado en el repo con fecha. Base contra la cual comparar M2 y M3.
3h
○
Disavow toolfile submitted a Google Search Console Lista de dominios de backlinks tóxicos (heredados de Rodanet) cargada en GSC vía Disavow Tool. Procesamiento por Google: 2-4 semanas.
2h
○
Configuración del primer experimento documentado (M2 ready) A/B preparado para arrancar M2: hipótesis (ej. reescribir title del Home subiendo CTR de 0,78% a 1,5%), métrica primaria (CTR GSC), métrica secundaria (clicks/día), período (4 semanas), criterio de éxito.
2h
○
Reporte M1 (PDF + dashboard live) + call de revisión con Xavi 30 min de demo: lo que está vivo, baseline congelado, score evolución (0 → 66+), lista de gaps priorizados, plan operativo M2. Decisión conjunta de qué quick wins atacar primero según señales reales.
